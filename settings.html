TinyMobile
ปรับหน้าตาแชทให้เข้ากับมือถือ (ข้อความเต็มบับเบิ้ล) + ลดงาน render ให้ลื่นขึ้น + ทำให้ UI ทั้งแอปเดินตามสีธีมของ SillyTavern เอง (ยุบรวม TinyTheme เข้ามาแล้ว)
เลย์เอาต์ข้อความ
ประสิทธิภาพ
สีตามธีม SillyTavern
ยุบมาจาก TinyTheme — แก้จุดที่ SillyTavern เขียนสีตายตัวไว้ (ไม่ใช่แค่ในแชท ครอบคลุมทั้งแอป) ใช้ได้กับทุกธีมของ ST เอง ไม่ต้องพึ่ง Custom CSS อีก
ตัวอักษร/ย่อหน้าในแชท
ยุบมาจาก TinyTheme — ใช้เฉพาะกับข้อความในแชท ไม่กระทบตัวอักษรของ UI ส่วนอื่น
0 = ใช้ขนาดตัวอักษรของ ST ตามปกติ
0 = ใช้ระยะบรรทัดของ ST ตามปกติ
เยื้องเฉพาะย่อหน้าจริง (เว้น 2 บรรทัดขึ้นไป) ไม่กระทบการขึ้นบรรทัดใหม่ปกติ
โหมดมือถือ (แก้ค่าตั้งค่าของ SillyTavern เอง)
ปุ่มนี้จะไปแก้ "ค่าตั้งค่าผู้ใช้" ของ SillyTavern จริง (ไม่ใช่แค่ CSS ของ TinyMobile) เพื่อลดงานตอน AI พิมพ์ให้มากขึ้นอีกขั้น — เห็นตารางก่อน-หลังแล้วค่อยกดยืนยัน และกดคืนค่าเดิมได้ตลอด
